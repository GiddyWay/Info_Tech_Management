# Паспорт проекта: ATI.SU

**Курс:** Управление информационными технологиями на предприятии  
**Семестр:** осень/зима 2026  
**Объект исследования:** ATI.SU

## Полная версия паспорта

### 1. Бизнес

**ATI.SU** — цифровая платформа для участников рынка автомобильных грузоперевозок.

Для подтверждения финансового масштаба используется российское юридическое лицо **ООО ИА «АВТОТРАНСИНФО» (ИНН 7810518403)**, которое указано в официальных документах ATI.SU.

Источник: [ATI.SU — обработка персональных данных](https://ati.su/policies/data-subject-consent/)

### 2. Отрасль

**SaaS / цифровая платформа для транспортной логистики.**

Источник: [О логистической платформе ATI.SU](https://about.ati.su/)

### 3. Выручка

Выручка ООО ИА «АВТОТРАНСИНФО» за **2025 год — 1 475 795 000 ₽**.

Источники:
- [B2B.House — ООО ИА «АВТОТРАНСИНФО»](https://b2b.house/company/OOO-IA-AVTOTRANSINFO_fa38d09a-8f78-49e4-93c2-bcf65f83c1a0/)
- [Audit-it — ООО ИА «АВТОТРАНСИНФО»](https://www.audit-it.ru/contragent/1089847223663_ooo-ia-avtotransinfo)

Требование курса о выручке более 300 млн ₽ выполняется.

### 4. Способ подтверждения масштаба

**Публичные данные.**

Масштаб подтверждается двумя независимыми открытыми источниками бухгалтерской информации: B2B.House и Audit-it.

### 5. Направления выручки

По открытым данным можно выделить следующие направления монетизации:

- лицензии и платный доступ к возможностям ATI.SU;
- сервис «Площадки ATI.SU» для организации работы с перевозчиками;
- платные API и аналитические сервисы;
- сервис претензий с при поддержке юристов ATI.SU;
- сервис предоплаты за рейсы.

Точные доли направлений в выручке публично не раскрыты.

Источники:
- [Лицензии ATI.SU](https://help.ati.su/licenzii-uslugi-i-sposoby-oplaty)
- [Стоимость Площадок ATI.SU](https://help.ati.su/platforms-price)
- [API Средних ставок](https://help.ati.su/average-rate-api)

### 6. Клиенты и каналы

**Клиенты:** перевозчики, грузовладельцы, экспедиторы и компании, организующие автомобильные грузоперевозки.

**Каналы:** веб-платформа ATI.SU, мобильные приложения, API и корпоративные «Площадки ATI.SU».

Источники:
- [Что такое ATI.SU](https://help.ati.su/chto-takoe-avtotransinfo)
- [О платформе ATI.SU](https://about.ati.su/)

### 7. Что известно об ИТ на входе

По открытым данным:

- в ATI.SU работает **400+ сотрудников**;
- действует **более 30 команд разработки**;
- у компании есть публичные API и интеграции с внешними информационными системами.

Это используется только как подтверждение наличия собственной ИТ-функции. Её состояние и зона в паспорте не определяются — это задача ПР1.

Источники:
- [Работа в ATI.SU](https://job.ati.su/)
- [API Средних ставок](https://help.ati.su/average-rate-api)

### 8. Доступ студента к сведениям

**Только открытые данные.**

Используются официальный сайт ATI.SU, справочный центр, карьерный сайт, публичные вакансии и открытая бухгалтерская информация.

### 9. Ограничения на раскрытие

В проекте используются только публично доступные сведения. Закрытые внутренние данные компании не используются, поэтому нормировка показателей на этапе паспорта не требуется.

## Краткая версия паспорта — 5 строк

1. **Бизнес:** ATI.SU — SaaS / цифровая платформа для транспортной логистики.
2. **Масштаб:** выручка ООО ИА «АВТОТРАНСИНФО» — 1 475 795 000 ₽ за 2025 год; подтверждение — публичные данные B2B.House и Audit-it.
3. **Направления:** лицензии и платные функции ATI.SU, «Площадки ATI.SU», платные API и аналитика; доли не раскрыты.
4. **ИТ-функция:** предварительно — 400+ сотрудников и более 30 команд разработки; состояние и зона будут определены в ПР1.
5. **Ограничения:** используются только открытые данные; закрытые сведения не используются, нормировка не требуется.
